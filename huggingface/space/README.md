# VoxLegal Indian Legal Model Demo

A quota-limited demo of the VoxLegal Indian Legal LoRA adapter. This is a research/demo interface, not legal advice. The adapter depends on the Llama 3.1 8B base model.

Set the `MODEL_REPO_ID` variable in the Space settings to your public Hugging Face model repository (for example, `your-username/voxlegal-indian-legal-llm`).

This Space runs on Hugging Face ZeroGPU. GPU availability and daily usage quotas apply.
